# Flowline Frontend

Minimal Next.js (App Router, TypeScript) scaffold with `Login` and `Todo` page routes.

## Getting started

```bash
npm install
npm run dev
```

Then visit:

- `/login` — Login page
- `/todo` — Todo page

`/` redirects to `/login`.

## Scripts

- `npm run dev` — start the local dev server
- `npm run build` — production build
- `npm run type-check` — TypeScript check
- `npm test` — run the Vitest test suite
